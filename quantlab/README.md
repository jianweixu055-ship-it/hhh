# 徐健伟量化选股：盈利证据审计版

本版修正的是回测和证据质量；尚未证明策略可以稳定实盘盈利。详细结论见 `分析与优化报告.md`。

## 启动

需要 Node.js 18 或以上，无需安装 npm 依赖。在本文件目录运行：

```sh
node server.js
```

在本机浏览器打开 `127.0.0.1:8666/audit.html` 查看审计；`index.html` 保留选股研究界面。Windows 也可双击 `启动审计版.bat`。

服务默认仅绑定本机地址，不会自动打开公网隧道。旧 `.lnk` 和原程序中的绝对路径不适用于此目录。退出运行 Node 的窗口即可停止服务。

## 复算

```sh
node research.js
python confidence.py
node --test
```

前两步应按顺序运行。Python 3 的 `confidence.py` 需要 NumPy（测试版本见 requirements-analysis.txt）；只运行网页不需要 Python。`research.js` 生成完整 JSON，`confidence.py` 补充 4 周分块重抽样区间并导出 CSV 与网页摘要。输入数据 SHA-256 保存在结果中。不要把未平仓卖出悄悄删掉或标记成已实现盈亏。

默认每笔名义金额为 50,000 元（用户回复“5w”，按所问单笔金额解释）；如果是账户总额，请在审计页输入实际单票分仓金额。佣金暂设万三、最低 5 元，双边滑点各 0.1%，按页面所列税费估算。输入为前复权价格：费用仅为名义敞口示例，不是实际原价整手成交复原。

`guarded` 是固定风控对照，2026 年没有证明改善收益，不应当成优化成功的实盘策略。2026 年数据此前已被原软件使用，不能声称是未见过的样本外验证。

## 数据与功能边界

- `lab_data.json` 来自用户附件，没有改写。其“截至 10 月 21 日”的元数据与实际最晚 10 月 13 日信号不同。没有独立验证提供方行情或重建原信号池。
- 本次云端离线复算、网页和回归测试通过。新浪和腾讯行情请求被当前云环境出口返回 403，实时选股、实时数据回退链路及 AI 外部接口未验证。离线审计不受影响。
- 原标称 86.5% 与 82.1% 的策略缺少逐笔交易、成交队列及生成程序，暂停提供它们的实盘信号。
- 单股票回测仅提供均线诊断与持有基准。收盘强度所需历史市值、换手与信号快照应在审计页检查，不再提供原本实际没有实现的单股回测选项。
- 没有完整交易日期、原价、复权事件、成交记录和历史证券池，故未生成账户级年化、回撤或未来赚钱概率。旧模拟交易/价格复盘页只供记录与观察，不是本次已验证的实盘模型。
- 数据源切换可能导致信号日期与指标时点不一致；在线结果标记为研究候选，不能自动视为完成了历史规则复核。
- 不含原 `ai_key.json`、公网隧道及守护脚本；未使用上传的密钥。若原字段是有效密钥且曾经分享或暴露，请到提供商撤销更换。AI 是可选功能，不参与本次回测。

新云任务已有独立环境，应使用现有文件目录，不需要另建 Git worktree。保留的依赖和文件可以复用；运行中的进程需要重新启动。

第三方：`echarts.min.js` 为 Apache ECharts 5.6.0，经原页面的 SHA-384 SRI 校验后本地保存；许可见 `ECHARTS-LICENSE.txt`。

# 徐健伟量化选股 · 短线研究工作台

在原软件基础上增加看盘、短线条件核验和小资金风险测算。所有源代码、测试和报告直接保存在本仓库。

部署地址：<https://jianweixu055-ship-it.github.io/hhh/>（GitHub Pages 首次启用后生效）。当前源码已推送；仓库连接缺少创建 Pages 的权限，需要仓库管理员在 Settings → Pages 将 Source 设为 GitHub Actions。

## 功能与边界

- 腾讯行情直连：主要指数、股票快照、日/周/月前复权 K 线、成交量和五档盘口，展示来源日期时间。
- 代码/名称搜索、自选收藏、排序、CSV 导出、观察笔记和最近一次核验快照；个人记录仅保存在浏览器本机。
- 沿用原收盘强度规则：涨幅 2–6%、换手 3–10%、量比 1.2–2.5、总市值小于 50 亿、20 日涨幅小于 30%、收盘强度至少 90%，剔除 ST / 退市风险名称。
- 区分“排除、缺数据、盘中预筛、收盘条件完整”。条件完整仍不是买入指令，不代表未来盈利概率。
- 资金约束：默认以 **5 万元账户总额**为示例，单票上限 20%、单笔风险预算 0.5%、测算止损距离 4%，均可修改，未被证明为最优参数。买不起一手或含成本风险超过预算时，不给完整候选。
- 资金测算计入佣金万三、每边最低 5 元、过户费、卖出印花税和双边各 0.1% 滑点。适用板块按 100 股整手；科创/北交所特殊申报规则未纳入股数测算。T+1、跳空、跌停可能让亏损超过测算值。
- 导出全部核验 CSV（含排除/缺失记录）和完整 JSON 快照（来源时间、行情、历史日K、资金测算、规则版本）。记录不是实盘成交证明。
- 实时连接失败会报错，**不自动用演示数据填充**。用户可主动切换演示体验；所有演示数字均为合成示例，不进入真实策略验证。

默认观察池只有 8 只股票，可搜索和通过自选扩展；另提供附件中 356 只历史信号股票构成的研究池。**均不是全市场证券池，存在历史存续筛选偏差。**

收盘条件完整需要今日行情、15:00 后的来源时间以及匹配的当日完整日K。历史复权日K与前收盘口径不一致时不计算通过。交易日历尚未完整接入：旧行情可供看盘，但不会被认定为今日新信号。

原标称 86.5% / 82.1% 的两套策略因缺少逐笔证据，继续停用。新增资金条件只约束可执行性，**尚无证据证明提高了盈利胜率**；已测试但未改善近期收益的过滤/止损组合没有设为默认。详见 [分析报告](reports/分析与优化报告.md) 和 [原审计说明](quantlab/README.md)。

## 运行与验证

需要 Node.js 20 或以上；主程序无 npm 外部依赖，无需安装依赖包。

```sh
npm start
```

在本机浏览器打开 `127.0.0.1:8080`。关闭运行终端即可停服；可使用 `PORT`、`HOST` 配置监听，默认仅绑定本机。

```sh
npm test
npm run build
```

测试包含原回测引擎和新增规则。构建生成 `_site/`，只复制所需前端和报告，不复制密钥、服务端脚本和测试；生成产物不提交，生成逻辑位于 `scripts/build.mjs`。

可选浏览器检查需要 Python Playwright 与 Chromium，在服务启动后运行：

```sh
QL_TEST_CHROMIUM=/usr/bin/chromium python tests/browser-smoke.py
```

该检查主动阻断外部行情，验证断网提示和演示隔离；真实行情连接单独验证。云端浏览器若不信任平台代理证书，应导入环境提供的 CA，保留 TLS 校验，不使用忽略证书错误的参数。

## 发布与原软件

`.github/workflows/pages.yml` 在推送 `main` 后自动测试、构建、部署。仓库 Pages 来源应为 **GitHub Actions**。测试失败不会发布。

首次启用 Pages 后，可在仓库 Actions → Test and publish stock workbench → Run workflow 重新发布。构建和发布是独立任务，首次 Pages 配置未完成时仍可下载构建任务生成的静态站点产物。

原软件保留在 `quantlab/`。静态站点可访问其审计页；原版 AI 和服务端代理需要本机运行 `quantlab/server.js`，GitHub Pages 不运行 Node 后端。上传的 AI 密钥未复制到仓库或发布产物。

| 位置 | 内容 |
|---|---|
| `index.html`、`assets/` | 新看盘与短线条件核验页面 |
| `assets/scanner.mjs` | 可独立测试的规则和含费用资金测算 |
| `assets/market.mjs` | 行情解析、直连及隔离的演示数据 |
| `quantlab/` | 原软件、修复后的回测、历史数据与审计 |
| `reports/` | 上轮审计与回测报告 |
| `tests/` | 新单元测试和浏览器检查 |
| `scripts/` | 开发服务与静态构建 |

Apache ECharts 5.6.0 复用原项目已校验的本地文件；许可见 `quantlab/ECHARTS-LICENSE.txt`。
